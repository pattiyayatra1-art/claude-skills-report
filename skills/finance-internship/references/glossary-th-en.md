# ศัพท์การเงิน/ธนาคาร ไทย-อังกฤษ

รวมคำที่เด็กฝึกงานมักเจอ เรียงตามหมวด ใช้อ้างอิงเวลาอ่านเอกสารหรือเขียนรายงาน
คำแปลเป็นความหมายทั่วไป ถ้าบริษัทใช้คำแปลเฉพาะของตนเอง ให้ยึดตามบริษัท

## หน่วยงานกำกับและกฎหมาย

| ไทย | อังกฤษ / ตัวย่อ | ความหมายสั้นๆ |
|---|---|---|
| ธนาคารแห่งประเทศไทย | Bank of Thailand (BOT) | ธนาคารกลาง กำกับดูแลสถาบันการเงินและระบบการชำระเงิน |
| สำนักงานคณะกรรมการ ก.ล.ต. | Securities and Exchange Commission (SEC) | กำกับตลาดทุนและผู้ประกอบธุรกิจหลักทรัพย์ |
| สำนักงานคณะกรรมการกำกับและส่งเสริมการประกอบธุรกิจประกันภัย | Office of Insurance Commission (OIC) | กำกับธุรกิจประกันภัย |
| สำนักงานป้องกันและปราบปรามการฟอกเงิน | AMLO | หน่วยงานด้านการฟอกเงินและการตรวจสอบทรัพย์สิน |
| พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 | Personal Data Protection Act (PDPA) | กฎหมายคุ้มครองข้อมูลส่วนบุคคล |
| การป้องกันและปราบปรามการฟอกเงิน | Anti-Money Laundering (AML) | มาตรการป้องกันการนำเงินผิดกฎหมายเข้าระบบการเงิน |
| รู้จักลูกค้า | Know Your Customer (KYC) | ขั้นตอนยืนยันตัวตนและข้อมูลลูกค้าก่อนเปิดบัญชี/ให้บริการ |
| การกำกับดูแลกิจการที่ดี | Corporate Governance | ระบบการบริหารและควบคุมภายในของบริษัท |
| การควบคุมภายใน | Internal Control | กระบวนการป้องกันความเสี่ยงและความผิดพลาดภายในองค์กร |
| การปฏิบัติตามกฎเกณฑ์ | Compliance | การทำตามกฎหมาย ระเบียบ และมาตรฐานที่เกี่ยวข้อง |

## ผลิตภัณฑ์และบัญชี

| ไทย | อังกฤษ | ความหมายสั้นๆ |
|---|---|---|
| บัญชีออมทรัพย์ | Savings Account | บัญชีเงินฝากที่ถอนได้ มีดอกเบี้ย |
| บัญชีกระแสรายวัน | Current Account | บัญชีเงินฝากที่ถอนได้ไม่จำกัดครั้ง มักไม่มีดอกเบี้ยหรือดอกเบี้ยต่ำ |
| เงินฝากประจำ | Fixed Deposit (FD) | ฝากเงินไว้ตามระยะเวลาที่กำหนด |
| สินเชื่อ | Loan / Credit | การให้กู้ยืมเงิน |
| สินเชื่อบ้าน | Mortgage / Housing Loan | สินเชื่อที่มีหลักประกันเป็นอสังหาริมทรัพย์ |
| สินเชื่อส่วนบุคคล | Personal Loan | สินเชื่อให้บุคคลธรรมดาโดยไม่ต้องมีหลักประกัน |
| สินเชื่อรายย่อย / SME | Micro / SME Loan | สินเชื่อสำหรับบุคคลและธุรกิจขนาดเล็ก-กลาง |
| บัตรเครดิต | Credit Card | บัตรที่ให้วงเงินใช้ก่อนแล้วชำระทีหลัง |
| หนี้ที่ไม่ก่อให้เกิดรายได้ | Non-Performing Loan (NPL) | สินเชื่อที่ผู้กู้ค้างชำระเกินกำหนด |
| หนี้ค้างชำระ / ค้างชำระ | Overdue / Delinquency | ยอดที่ยังไม่ได้ชำระตามกำหนด |
| สำรองหนี้สูญ | Loan Loss Provision | เงินสำรองที่ตั้งไว้สำหรับหนี้ที่อาจสูญ |
| อัตราดอกเบี้ย | Interest Rate | ราคาของการใช้เงิน |
| ดอกเบี้ยเงินฝาก / ดอกเบี้ยเงินกู้ | Deposit Rate / Lending Rate | อัตราที่ธนาคารจ่ายให้ผู้ฝาก / คิดกับผู้กู้ |
| อัตราดอกเบี้ยนโยบาย | Policy Rate | อัตราดอกเบี้ยที่ ธปท. ใช้กำหนดทิศทางนโยบายการเงิน |
| ประกันชีวิต | Life Insurance | การประกันความเสี่ยงด้านชีวิต |
| ประกันวินาศภัย | Non-Life / General Insurance | การประกันทรัพย์สิน รถยนต์ สุขภาพ ฯลฯ |
| กองทุนรวม | Mutual Fund | เงินลงทุนรวมจากหลายคนบริหารโดยผู้จัดการกองทุน |
| หุ้นสามัญ | Common Stock / Equity | ตราสารแสดงความเป็นเจ้าของบริษัท |
| พันธบัตร | Bond | ตราสารหนี้ที่ผู้ออกจ่ายดอกเบี้ยและคืนเงินต้น |
| ตั๋วเงินคลัง | Treasury Bill (T-Bill) | ตราสารหนี้ระยะสั้นของรัฐบาล |

## การวิเคราะห์และการเงินองค์กร

| ไทย | อังกฤษ | ความหมายสั้นๆ |
|---|---|---|
| งบการเงิน | Financial Statements | งบกำไรขาดทุน งบฐานะการเงิน งบกระแสเงินสด |
| งบกำไรขาดทุน | Income Statement / P&L | แสดงรายได้ ค่าใช้จ่าย และกำไรในช่วงเวลาหนึ่ง |
| งบแสดงฐานะการเงิน | Balance Sheet | สินทรัพย์ หนี้สิน และส่วนของผู้ถือหุ้น ณ วันใดวันหนึ่ง |
| งบกระแสเงินสด | Cash Flow Statement | การไหลเข้าออกของเงินสดจากกิจกรรมต่างๆ |
| รายได้ดอกเบี้ยสุทธิ | Net Interest Income (NII) | ดอกเบี้ยรับหักดอกเบี้ยจ่าย |
| อัตราส่วนเงินกองทุน | Capital Adequacy Ratio (CAR) | สัดส่วนเงินกองทุนต่อสินทรัพย์เสี่ยง |
| อัตราผลตอบแทนต่อสินทรัพย์ | Return on Assets (ROA) | กำไรสุทธิหารด้วยสินทรัพย์รวม |
| อัตราผลตอบแทนต่อส่วนของผู้ถือหุ้น | Return on Equity (ROE) | กำไรสุทธิหารด้วยส่วนของผู้ถือหุ้น |
| อัตราส่วนสภาพคล่อง | Liquidity Ratio | ความสามารถในการจ่ายหนี้ระยะสั้น |
| อัตราส่วนหนี้สินต่อทุน | Debt-to-Equity (D/E) | สัดส่วนหนี้สินเทียบกับทุน |
| มูลค่าปัจจุบันสุทธิ | Net Present Value (NPV) | มูลค่าปัจจุบันของกระแสเงินสดหักเงินลงทุน |
| อัตราผลตอบแทนภายใน | Internal Rate of Return (IRR) | อัตราผลตอบแทนที่ทำให้ NPV เท่ากับศูนย์ |
| ความเสี่ยงตลาด | Market Risk | ความเสี่ยงจากการเปลี่ยนแปลงราคาตลาด |
| ความเสี่ยงด้านเครดิต | Credit Risk | ความเสี่ยงที่คู่สัญญาไม่ชำระหนี้ |
| ความเสี่ยงด้านสภาพคล่อง | Liquidity Risk | ความเสี่ยงที่ไม่มีเงินพอจ่ายเมื่อถึงกำหนด |
| ความเสี่ยงด้านปฏิบัติการ | Operational Risk | ความเสี่ยงจากกระบวนการ คน ระบบ หรือเหตุการณ์ภายนอก |
| การทดสอบภาวะเครียด | Stress Testing | การทดสอบว่าธนาคารจะรับมือสถานการณ์เลวร้ายได้หรือไม่ |

## เทคโนโลยีการเงินและการชำระเงิน

| ไทย | อังกฤษ | ความหมายสั้นๆ |
|---|---|---|
| ฟินเทค | Fintech | เทคโนโลยีทางการเงิน |
| การชำระเงินอิเล็กทรอนิกส์ | Electronic Payment | การจ่ายเงินผ่านระบบดิจิทัล |
| พร้อมเพย์ | PromptPay | ระบบชำระเงินแบบโอนทันทีผ่านเลขอ้างอิงบัญชี |
| เปิดบัญชีออนไลน์ | Digital Onboarding / e-KYC | การเปิดบัญชีผ่านระบบดิจิทัล |
| เปิดเผยข้อมูลผ่าน API | Open API / Open Banking | การแชร์ข้อมูลผ่านอินเทอร์เฟซ API ตามความยินยอม |
| การจัดการข้อมูลลูกค้า | Customer Data Management | การจัดเก็บและใช้ข้อมูลลูกค้าอย่างเหมาะสม |
| ตรวจจับการทุจริต | Fraud Detection | ระบบตรวจจับธุรกรรมผิดปกติ |
| ความปลอดภัยสารสนเทศ | Information Security | การปกป้องข้อมูลและระบบ |

## คำศัพท์ทั่วไปในการทำงานธนาคาร

| ไทย | อังกฤษ | ความหมายสั้นๆ |
|---|---|---|
| สาขา | Branch | สถานที่ให้บริการลูกค้า |
| สำนักงานใหญ่ | Head Office | หน่วยงานกลาง |
| ฝ่ายปฏิบัติการ | Operations | งานประมวลผลธุรกรรมและเอกสาร |
| ฝ่ายบริหารความเสี่ยง | Risk Management | ระบุ วัด และควบคุมความเสี่ยง |
| ฝ่ายตรวจสอบภายใน | Internal Audit | ตรวจสอบความเพียงพอของการควบคุมภายใน |
| ฝ่ายกฎหมาย/กำกับ | Legal / Regulatory Affairs | ดูแลกฎหมายและการยื่นรายงานต่อหน่วยงานกำกับ |
| ฝ่ายวิเคราะห์ข้อมูล | Data Analytics | วิเคราะห์ข้อมูลเพื่อการตัดสินใจ |
| รายงานผู้บริหาร | Management Report / MIS | รายงานข้อมูลสรุปสำหรับผู้บริหาร |
| ข้อตกลงระดับการให้บริการ | Service Level Agreement (SLA) | ข้อตกลงเรื่องระดับและเวลาของการให้บริการ |
| วันทำการ | Business Day | วันที่ทำการ ไม่รวมวันหยุดราชการ/วันหยุดธนาคาร |
