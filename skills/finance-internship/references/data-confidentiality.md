# ข้อมูลลับและข้อมูลส่วนบุคคล: แนวปฏิบัติสำหรับเด็กฝึกงาน

เอกสารนี้สรุปแนวปฏิบัติพื้นฐาน ไม่ใช่คำแนะนำทางกฎหมาย ให้ยึดนโยบายจริงของบริษัท
และถ้าไม่แน่ใจให้ถามพี่เลี้ยงหรือฝ่ายกฎหมาย/ความมั่นคงสารสนเทศก่อนเสมอ

## 1. จำแนกข้อมูลก่อนใช้ทุกครั้ง

| ระดับ | ตัวอย่าง | การใช้กับ AI / เครื่องมือภายนอก |
|---|---|---|
| ข้อมูลส่วนบุคคล (Personal Data) | ชื่อ เลขบัตรประชาชน ที่อยู่ เบอร์โทร อีเมล ข้อมูลการเงินที่ระบุตัวบุคคลได้ | **ห้ามใส่** ต้องลบตัวระบุออกหรือใช้รหัสแทน |
| ข้อมูลอ่อนไหว (Sensitive Personal Data) | ข้อมูลสุขภาพ ศาสนา ประวัติอาชญากรรม ข้อมูลชีวภาพ | **ห้ามใส่เด็ดขาด** |
| ข้อมูลลับ/ภายใน (Confidential / Internal) | แผนธุรกิจ ราคาเสนอ ผลประเมิน ข้อมูลการเงินที่ยังไม่เปิดเผย | **ห้ามใส่** เว้นแต่บริษัทอนุญาต |
| ข้อมูลสาธารณะ (Public) | รายงานประจำปีที่เผยแพร่แล้ว ประกาศของหน่วยงานกำกับ บทความทั่วไป | ใช้ได้ |

## 2. วิธีทำให้ข้อมูลไม่ระบุตัวตน (Anonymize / Pseudonymize)

- แทนชื่อด้วยรหัส: `ลูกค้า A`, `CUST_001`
- ตัดเลขบัญชี/บัตรออกทั้งหมด หรือแสดงเฉพาะ 4 ตัวท้ายแบบมาสก์ `XXX-X-X1234-X` (ตรวจว่ายังระบุตัวได้หรือไม่)
- ปัดหรือรวมข้อมูล: แทนยอดรายบุคคลด้วยช่วง (เช่น "10,000–50,000 บาท") หรือยอดรวมตามกลุ่ม
- ลบคอลัมน์ที่ระบุตัวบุคคลได้เมื่อรวมกับคอลัมน์อื่น เช่น วันเกิด + รหัสไปรษณีย์ + เพศ
- ระวังข้อความอิสระ (free text) เช่น บันทึกการติดต่อ อาจมีชื่อหรือเบอร์โทรซ่อนอยู่

## 3. สิ่งที่ควรทำเมื่อพลาดส่งข้อมูลลับไป

1. หยุดทันที อย่าทำงานต่อกับข้อมูลนั้น
2. ลบข้อความ/ไฟล์ออกจากแชตหรือเครื่องมือที่ใช้ ถ้าทำได้
3. แจ้งพี่เลี้ยงทันที ไม่ปิดบัง (การรายงานเร็วช่วยลดความเสียหาย)
4. ทำตามขั้นตอนการรายงาน incident ของบริษัท

## 4. ความปลอดภัยของบัญชีและอุปกรณ์

- ไม่แชร์รหัสผ่านหรือ OTP ไม่ว่ากับใคร รวมถึงในแชต
- ไม่ใส่ API key, token, หรือ credential ในแชต/โค้ด/ไฟล์ที่แชร์
- ไม่บันทึกไฟล์งานลงอุปกรณ์ส่วนตัวหรือ USB ที่ไม่ได้รับอนุญาต
- ไม่ถ่ายรูปหน้าจอที่มีข้อมูลลูกค้าหรือข้อมูลลับส่งออกนอกระบบ
- ล็อกหน้าจอเมื่อลุกจากที่นั่ง และไม่ทิ้งเอกสารไว้ที่เครื่องพิมพ์

## 5. หลักคิดเมื่อไม่แน่ใจ

ถามตัวเองสองข้อ:
1. ถ้าข้อมูลนี้รั่วออกไป ลูกค้าหรือบริษัทจะเสียหายไหม
2. ฉันมีสิทธิ์ใช้ข้อมูลนี้กับเครื่องมือนี้เพื่องานนี้จริงหรือไม่

ถ้าคำตอบข้อใดไม่ชัดเจน ให้หยุดแล้วถามพี่เลี้ยงก่อน
