ที่มา: FS FY2025 · MD&A 3Q26 · ออสเตรเลีย: Quartr (แหล่งรอง)

บทพูด: ศุภาลัยเป็นผู้พัฒนาที่อยู่อาศัยที่พึ่งรายได้จากการขายอสังหาฯ เกือบทั้งหมด คือ 95.7% ของรายได้ปี 2025 สิ่งที่ต้องจำไว้ตลอดเด็คคือ รายได้ของธุรกิจนี้มาจากการโอนกรรมสิทธิ์ ดังนั้น Backlog 15,264 ล้านบาท และยอดขายล่วงหน้า (Presales) ที่ลดลง 9% เป็นตัวบอกรายได้ในอนาคต สัดส่วนรายได้จากขายอสังหาฯ = 23,714 / 24,772 = 95.7% (คำนวณเอง) Backlog โอนใน Q4-26 ราว 5,263 และอีก 10,001 ภายใน 3 ปี ข้อมูลโครงการออสเตรเลีย (25 โครงการ มูลค่ารวม 207,300 ล้านบาท) มาจากสรุปของ Quartr ซึ่งเป็นแหล่งรอง ควรยืนยันกับ 56-1 One Report ก่อนใช้อ้างอิงทางการ ข้อมูลตลาดย้ายไปสไลด์ราคา: ราคาปิด 15.40 บาท มูลค่าตลาด 30,077 ล้านบาท (SET คิดบน 1,953.05 ล้านหุ้นที่รวมหุ้นซื้อคืน 51 ล้านหุ้น) Free float 54.51% ต่างชาติถือ 12.99% (เพดาน 35%) ตาม SET ภาพขวา: ภาพมุมสูงหมู่บ้านจัดสรร จาก Unsplash โดย Maximillian Conacher (Unsplash License ใช้ได้ฟรี) เป็นภาพประกอบ ไม่ใช่โครงการของศุภาลัย
