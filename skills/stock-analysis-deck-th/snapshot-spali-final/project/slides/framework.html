ที่มา: กรอบ Analyst Prompt ของผู้จัดทำ · FMP ใช้ไม่ได้ในแผนปัจจุบัน (ACCESS DENIED) จึงใช้เอกสารบริษัท SET และแหล่งรองตรวจข้าม

บทพูด: ก่อนดูตัวเลข ขอวางกติกาการทำงานกับ AI ไว้ 5 ขั้น เริ่มจากกำหนดแหล่งข้อมูล ช่วงเวลา และตัวชี้วัดให้ชัด จากนั้นทุกตัวเลขต้องผ่าน Data Audit และคำนวณซ้ำ ส่วนข้อมูลที่ขาดให้ระบุว่าไม่มีข้อมูล ไม่ให้ AI เดา กฎทอง 5 ข้อ: เริ่มจากคำถาม, รู้ที่มาของตัวเลข, เชื่อมงบ 3 ชุด, ตรวจสอบข้อสรุป AI เสมอ, ประเมินมูลค่าเทียบราคาตลาด รายละเอียด: Source = งบการเงินรวม FY2021–2025 (EY), MD&A 3Q26, IR Highlights, SET factsheet และบทวิเคราะห์เป็นความเห็นรอง · Period = FY2021–2025 (5 ปี), 9M26 เทียบ 9M25, 3Q26 เทียบ 3Q25 งบรวม หน่วยล้านบาท · Metrics = การเติบโต ความสามารถทำกำไร คุณภาพกำไร สภาพคล่องและหนี้ กระแสเงินสด มูลค่า · Evidence = ทุกตัวเลขผ่าน Data Audit 7 ข้อและคำนวณซ้ำด้วย Python เทียบกับตัวเลขที่บริษัทรายงาน · Limit = ไม่ประมาณข้อมูลที่ขาด ระบุ “ไม่มีข้อมูล” เช่น สาเหตุภาษี Q3 ต่ำ และรายละเอียดนโยบายปันผลใหม่ ข้อมูลจาก FMP ใช้ไม่ได้ในแผนปัจจุบัน (ACCESS DENIED) จึงใช้เอกสารบริษัท SET และแหล่งรองเพื่อตรวจข้าม
