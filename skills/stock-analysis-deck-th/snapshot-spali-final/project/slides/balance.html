บทพูด: สินทรัพย์รวมโตจาก 71,432 เป็น 99,285 ล้านบาท หรือ 39% แต่ส่วนที่โตเร็วที่สุดคือหนี้มีดอกเบี้ย จาก 19,890 เป็น 37,988 ล้านบาท เกือบเท่าตัว และเงินส่วนใหญ่ไปจมอยู่ในต้นทุนโครงการที่ยังไม่ได้โอน ตัวเลขงบดุลครบ 5 ปี (ล้านบาท, 2021/2022/2023/2024/2025): สินทรัพย์รวม 71,432 / 79,924 / 86,126 / 96,231 / 99,285 · หนี้สินรวม 28,506 / 32,461 / 34,661 / 42,011 / 44,499 · ส่วนของผู้ถือหุ้น 42,926 / 47,463 / 51,465 / 54,220 / 54,786 · หนี้มีดอกเบี้ย 19,890 / 24,536 / 27,164 / 34,187 / 37,988 · เงินสด 1,626 / 1,315 / 4,711 / 5,123 / 3,788 · ต้นทุนโครงการ 62,104 / 65,675 / 71,125 / 74,641 / 77,448 A = L + E ตรงทุกปี (ผลต่าง ±0.1 จากการปัดตัวเลข) หนี้มีดอกเบี้ย = ตั๋วเงินจ่าย + เงินกู้ + หุ้นกู้ (ปี 2025: 6,163 + 9,961 + 21,864 = 37,988) เงินสดและหนี้มีดอกเบี้ยปี 2022–2024 ตรวจข้ามกับ StockAnalysis (แหล่งรอง) และกระทบยอดกับ Net gearing ที่บริษัทรายงานทุกปี ต้นทุนโครงการปี 2022 อ่านจากตัวเลขเปรียบเทียบใน FS FY2023 การเปลี่ยนแปลง: 99,285/71,432 − 1 = +39.0% · 37,988/19,890 − 1 = +91.0% · 77,448/62,104 − 1 = +24.7% · 54,786/42,926 − 1 = +27.6% กราฟ: แท่งล่าง = ส่วนของผู้ถือหุ้น แท่งบน = หนี้สิน (ยอดรวมปี 2025 ตัวเลขสีทอง)
