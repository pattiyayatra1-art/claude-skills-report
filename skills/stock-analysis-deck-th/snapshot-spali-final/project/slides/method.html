SPALI · 3

บทพูด: ความต่างระหว่างผลงานที่ดีกับไม่ดีเริ่มที่คำสั่ง ถ้าสั่งแค่ว่าช่วยวิเคราะห์ SPALI AI จะดึงตัวเลขบรรทัดสุดท้ายมาสรุปแบบผิวเผิน เราจึงใช้ Analyst Prompt ที่ระบุแหล่ง ช่วงเวลา มิติที่ต้องวิเคราะห์ และห้ามเดาข้อมูลที่ขาด แล้วทำงานหกขั้น ขั้นที่ให้ AI ทำคือดึงข้อมูล คำนวณ และร่างการตีความ ส่วนขั้นที่คนต้องทำเองคือ Verify ตรวจกับงบจริง และ Challenge หาจุดที่ AI ผิด ก่อนสังเคราะห์เป็นสามสไลด์ แถบล่าง: ก่อนใช้ตัวเลขทุกตัว เราตอบเช็กลิสต์เจ็ดข้อ คือ เอกสารใด ปีหรือไตรมาส งบรวมหรือเฉพาะกิจการ Audited หรือไม่ หน่วย Reported หรือ Adjusted และนิยามเทียบได้ แล้วจึงกระทบยอด ผลคือผ่านครบ งบดุลกระทบยอดได้ทุกปี และ P/E ที่คำนวณเองตรงกับ SET (TTM กำไรสุทธิ 4,015.03 − 2,677.10 + 2,881.51 = 4,219.44 ÷ 1,902.05 ล้านหุ้น = EPS 2.218 → P/E 6.94) การประเมินมูลค่าใช้ 1,953.05 ล้านหุ้นซึ่งรวมหุ้นซื้อคืน 51 ล้านหุ้น ลำดับความน่าเชื่อถือของแหล่ง: งบที่ตรวจสอบแล้ว → MD&A และ SET → บทวิเคราะห์ (ความเห็นรอง) → AI (ใช้ช่วยสรุปเท่านั้น) หลักการจาก Workshop: AI is not the source. AI must work FROM a source. · Use AI for analytical acceleration, not analytical substitution
