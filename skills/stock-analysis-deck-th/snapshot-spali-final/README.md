# Snapshot สไลด์ SPALI ฉบับสุดท้าย (17 หน้า)

สำเนาไฟล์ของ Artifact (ชนิด Slides) ณ วันที่ 27 พ.ย. 2026 ตรวจแล้วว่าตรงกับตัวที่ผู้ใช้เปิดอยู่ในตัวแก้ไข (ไม่มีการแก้เพิ่มจากที่สร้าง)
ใช้เมื่อต้องการ **กู้คืน** หรือ **เริ่มแก้ต่อ**: publish โฟลเดอร์ `project/` ขึ้น Artifact ชนิด Slides (ส่ง deck.json, deck.css, slides/*.html) โดย `root` ชี้ที่โฟลเดอร์ที่มี `project/`
รูปภาพอ้างด้วย `/_blob/<id>` ซึ่งผูกกับ Artifact เดิม ถ้าสร้าง Artifact ใหม่ต้องอัปโหลดรูปใหม่แล้วแก้ id (ดู `scripts/pvx.js` ที่ map ชื่อไฟล์ ↔ id)
ไฟล์ `notes.json` = บทพูดในโน้ตผู้บรรยายรวมทุกหน้า
