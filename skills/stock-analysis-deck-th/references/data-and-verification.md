## สูตรที่ใช้ (ให้ตรงกันทุกสไลด์)
- เติบโต = ปีนี้ ÷ ปีก่อน − 1 · CAGR = (ปลาย ÷ ต้น)^(1/n) − 1
- OPM = กำไรจากการดำเนินงาน ÷ รายได้รวม (กำไรก่อนภาษี + ต้นทุนการเงิน − ส่วนแบ่ง JV) · NPM = กำไร ÷ รายได้รวม
- ROE = กำไรบริษัทใหญ่ ÷ ส่วนทุนบริษัทใหญ่ปลายปี · ROA = กำไร ÷ สินทรัพย์รวม · DuPont = NPM × รายได้/สินทรัพย์ × สินทรัพย์/ส่วนทุน (แยกการเปลี่ยนแปลงแบบ log)
- ปีที่ขายสต็อกหมด = สต็อก ÷ รายได้ขายอสังหาฯ ต่อปี
- Quick = (สินทรัพย์หมุนเวียน − สต็อก) ÷ หนี้สินหมุนเวียน · เงินสด ÷ หนี้ระยะสั้น (ตั๋วแลกเงิน + เงินกู้/หุ้นกู้ส่วนถึงกำหนดใน 1 ปี)
- D/E = หนี้สินรวม ÷ ส่วนทุนรวม · ND/EBITDA = (หนี้มีดอกเบี้ย − เงินสด) ÷ (OPM-ฐานกำไร + ค่าเสื่อม)
- ICR = (กำไรก่อนภาษี + ต้นทุนการเงิน) ÷ ต้นทุนการเงิน
- FCF = CFO − รายจ่ายลงทุน (PPE + อสังหาฯ เพื่อลงทุน + ซอฟต์แวร์) · Payout = DPS ÷ EPS
- มูลค่า: P/E × EPS, P/BV × BVPS (BVPS = ส่วนทุนบริษัทใหญ่ ÷ จำนวนหุ้น), DDM = DPS(1+g)/(COE−g) แล้วเฉลี่ย · MoS 20% = มูลค่า × 0.8

## ข้อผิดพลาดที่เจอจริง (ตรวจซ้ำทุกครั้ง)
| ปัญหา | แก้ |
|---|---|
| BVPS ใช้ส่วนทุน 57,440 ที่ไม่ตรงงบ | ใช้ส่วนทุนบริษัทใหญ่ตามงบดุล (53,728) → BVPS 27.51 · ผลต่อมูลค่ากลาง 15.24 → 14.89 |
| ROE ใช้ส่วนทุนรวม (รวม NCI) แต่กำไรเป็นของบริษัทใหญ่ | ใช้ส่วนทุนบริษัทใหญ่ทั้งตัวตั้งและตัวหาร |
| นับซื้อหุ้นคืน 3,000 เป็นปี 2021 | งบ FY2021 ชี้ว่าจ่ายปี 2020 → เงินจ่ายคืน 5 ปี = ปันผล 12,943 + ซื้อคืน 958 = 13,901 |
| สูตร ICR เขียนใช้กำไรจากการดำเนินงาน แต่ตัวเลข 8.1 คำนวณจากกำไรก่อนภาษี + ต้นทุนการเงิน | ใช้สูตรหลังและเขียนให้ตรง |
| ข้อความ "ยอดขายและกำไรลด 2 ปี" ผิด | ใช้ข้อเท็จจริงรายปี (2025: รายได้ −22.5% กำไร −35.1%) |
| "ตรวจ 8 ข้อ" แต่มี 7 | นับให้ตรง |
| คำ CFO/OCF ปนกัน | ใช้ CFO อย่างเดียว |
| ค่าที่เอามาจากเว็บสรุป (deepscope, investing) | ใช้เป็นตรวจข้ามเท่านั้น · นิยามรายได้รวมของคู่แข่งต่างกันเล็กน้อย ต้องบอกในโน้ต |

## เทียบคู่แข่ง
ใช้ปีเดียวกัน (FY ล่าสุด) · รายได้เติบโตต้องมีรายได้ปีก่อนจากแหล่งเดียวกัน · D/E = หนี้สินรวม ÷ ส่วนทุนรวม · ระบุว่าคิดเอง · P/E กลุ่มจากโบรกเกอร์เป็นความเห็นรอง
