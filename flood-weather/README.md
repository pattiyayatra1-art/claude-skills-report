# เช็กก่อนออกบ้าน: พยากรณ์อากาศและเฝ้าระวังน้ำท่วมแบบเรียลไทม์

เว็บไซต์หน้าเดียว (HTML/CSS/JavaScript ล้วน ไม่ต้อง build ไม่ต้องใช้ API key) แสดงข้อมูลสำคัญก่อนออกจากบ้านตามพื้นที่ที่เลือก

## ฟีเจอร์

- **สรุปก่อนออกจากบ้าน:** คำแนะนำและรายการของที่ควรพก (ร่ม หน้ากาก N95 ครีมกันแดด) สร้างจากข้อมูลจริง
- **แถบเตือนภัย:** น้ำท่วม พายุฝนฟ้าคะนอง ดัชนีความร้อน และลมกระโชกแรง
- **อากาศตอนนี้:** อุณหภูมิ อุณหภูมิที่รู้สึก ความชื้น ลม และทัศนวิสัย
- **ฝน 12 ชั่วโมงข้างหน้า:** กราฟโอกาสฝนและปริมาณฝนรายชั่วโมง
- **PM2.5:** จัดระดับตามเกณฑ์กรมควบคุมมลพิษ (ค่าเฉลี่ย 24 ชม.)
- **UV และเวลาพระอาทิตย์ขึ้น/ตก**
- **น้ำท่วม:**
  - ระดับน้ำจริงจากสถานีโทรมาตรใกล้ที่สุด (รัศมี 60 กม.) แสดงเป็น ม.รทก. % ของความจุลำน้ำ และ **สูงหรือต่ำกว่าตลิ่งกี่เมตร**
  - ปริมาณฝนสะสม 72 ชม. ที่ผ่านมา, 24 ชม. และ 7 วันข้างหน้า
  - แนวโน้มปริมาณน้ำในลำน้ำจากแบบจำลอง GloFAS
  - ระดับความเสี่ยงรวม 4 ระดับ (ต่ำ / เฝ้าระวัง / เสี่ยงสูง / วิกฤต) พร้อมเหตุผล
  - แผนที่สถานีวัดน้ำ ระบายสีตามสถานะ
- **พยากรณ์ 7 วัน**
- **เบอร์ฉุกเฉินและลิงก์ประกาศทางการ**
- อัปเดตอัตโนมัติทุก 10 นาที และอัปเดตทันทีเมื่อกลับมาที่แท็บ
- ใช้ตำแหน่ง GPS ได้ ค้นหาชื่อพื้นที่ได้ และจำพื้นที่ล่าสุดไว้
- รองรับมือถือ โหมดมืด และการใช้งานด้วยคีย์บอร์ด

## แหล่งข้อมูล

| ข้อมูล | แหล่ง | ความถี่อัปเดต |
|---|---|---|
| พยากรณ์อากาศ, UV | [Open-Meteo Forecast API](https://open-meteo.com/en/docs) (รวมแบบจำลองจาก ECMWF, NOAA, DWD ฯลฯ) | ทุก 15 นาที (ค่าปัจจุบัน) |
| PM2.5 / PM10 / AQI | [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) (Copernicus CAMS) | รายชั่วโมง |
| ปริมาณน้ำในลำน้ำ | [Open-Meteo Flood API](https://open-meteo.com/en/docs/flood-api) (Copernicus GloFAS) | รายวัน |
| ระดับน้ำสถานีโทรมาตร | [ThaiWater (สสน.)](https://www.thaiwater.net/) `api-v3.thaiwater.net/.../public/waterlevel_load` | ราว 10–15 นาที (ขึ้นกับสถานี) |
| ค้นหาพื้นที่ | Open-Meteo Geocoding API | - |
| แผนที่ | OpenStreetMap + Leaflet | - |

## ข้อจำกัดที่ควรรู้

- **ไม่มีแหล่งข้อมูลสาธารณะที่วัดความลึกน้ำท่วมบนถนนแบบเรียลไทม์ทุกจุด** เว็บนี้จึงบอกว่า "น้ำสูงแค่ไหน" จากระดับน้ำในลำน้ำเทียบกับตลิ่งที่สถานีใกล้ที่สุด และประเมินความเสี่ยงจากปริมาณฝน หากต้องการดูพื้นที่น้ำท่วมจริง ให้ใช้แผนที่ดาวเทียมของ GISTDA (มีลิงก์ในหน้าเว็บ)
- โครงสร้าง JSON ของ ThaiWater ไม่มีเอกสารอย่างเป็นทางการ โค้ดจึงอ่านหลายชื่อฟิลด์แบบยืดหยุ่น (`normalizeStation` ใน `js/app.js`) ถ้า API เปลี่ยนหรือเบราว์เซอร์บล็อก (CORS) ส่วนนี้จะแสดงลิงก์ไปที่ thaiwater.net แทน และส่วนอื่นยังทำงานต่อได้
- เกณฑ์ความเสี่ยงน้ำท่วมเป็นการประเมินเบื้องต้น ให้ยึดประกาศของ ปภ. และกรมอุตุนิยมวิทยาเป็นหลัก

## วิธีรันบนเครื่อง

ต้องเปิดผ่าน HTTP (ไม่ใช่การดับเบิลคลิกไฟล์) เพื่อให้ปุ่ม "ตำแหน่งของฉัน" ทำงาน:

```bash
cd flood-weather
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000

## วิธีนำขึ้นเว็บ (ฟรี)

- **GitHub Pages:** Settings → Pages → Source: Deploy from a branch → เลือก branch และโฟลเดอร์ แล้วเปิด `https://<user>.github.io/<repo>/flood-weather/`
- **Netlify / Vercel:** สร้างโปรเจกต์จาก repo นี้ ตั้ง publish directory เป็น `flood-weather` ไม่ต้องตั้ง build command

## โครงสร้างไฟล์

```
flood-weather/
├── index.html     โครงหน้าเว็บ
├── css/style.css  สไตล์ (รองรับมือถือและโหมดมืด)
└── js/app.js      ดึงข้อมูล วิเคราะห์ความเสี่ยง และแสดงผล
```

## ปรับแต่ง

ค่าที่ปรับได้อยู่ต้นไฟล์ `js/app.js`:

- `REFRESH_MS`: ความถี่การอัปเดต
- `STATION_RADIUS_KM`: รัศมีค้นหาสถานีวัดน้ำ
- `STATION_MAX_AGE_H`: ไม่แสดงสถานีที่ข้อมูลเก่ากว่านี้
- `QUICK_PLACES`: ปุ่มเลือกพื้นที่ด่วน
